# 💳 Financial Transaction Analysis

## 📌 Project Overview

This project analyzes financial transaction data using **SQL, MySQL, and Power BI** to identify transaction patterns, declined transactions, transaction amounts, risk categories, and daily trends.

The project includes SQL analysis, a synthetic transaction dataset, and an interactive Power BI dashboard.

## 🛠️ Tools Used

- 🐬 MySQL
- 🧮 SQL
- 📊 Power BI
- 🔄 Power Query
- 🧠 DAX

## 📈 Dashboard KPIs

- 🔵 **Total Transactions:** 2,000
- 🟢 **Total Transaction Amount:** $616.31K
- 🔴 **Declined Transactions:** 94
- 🟠 **Decline Rate:** 4.7%
- 🟣 **Medium-Priority Transactions:** 511

## 📊 Dashboard Features

- 📦 Transactions by Status
- ⚠️ Transactions by Risk Category
- 💰 Transaction Amount by Merchant Category
- 📉 Daily Transaction Amount Trend
- 🔎 Transaction Channel Filter
- 🎯 Risk Category Filter
- ✅ Transaction Status Filter

## 🎯 Project Goal

The goal of this project is to transform raw financial transaction data into meaningful business insights and build an interactive dashboard that helps users understand transaction performance and financial risk.
